Étape 4 — Mettre à jour GitHub
  1. Va sur ton dépôt GitHub → ouvre le fichier index.html → clique sur le crayon ✏️ pour éditer.
  2. Utilise Ctrl+H (Find & Replace) dans l'éditeur GitHub. Cherche const LOOT_DATA = [ pour localiser le début du bloc.
  3. Sélectionne tout le bloc const LOOT_DATA = [...]; (de const LOOT_DATA jusqu'au ]; inclus) et remplace-le par le bloc copié.
  4. Mets à jour le titre en haut du fichier : Midnight — Saison 2 (dans le header).
  5. Commit changes → GitHub Pages se met à jour en ~1 minute.
  6. N'oublie pas de cliquer 🔄 Nouvelle saison dans le panneau RL pour vider les réservations de la saison précédente !
